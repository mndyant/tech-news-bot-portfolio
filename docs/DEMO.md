# 外部通信なしで見る通知サンプル

`python main.py --demo` は `samples/digest.json` の自作記事と手書き要約を、実際の選別・整形処理へ渡します。
以下はその出力例です。実ニュースやGeminiの生成結果ではありません。

```text
今日の注目ニュース

・小さな検索改善
検索評価を自作データで確認するサンプルです。
<https://example.com/sample-1>

・本文のない項目
本文未取得：見出しの翻訳のみです。内容は原文で確認してください。
<https://example.com/sample-2>
```

- 入力3項目のうち、別ソースの同一URLをまとめて2件にします。
- 本文がない記事を「要約済み」とせず、見出し翻訳だけと表示します。
- このデモでは通知・状態保存を行わず、結果の `sent` は0です。
- `example.com` の記事URLは説明用です。実記事へのリンクではありません。

配送失敗時の保留、再試行、日本語でない要約の拒否、件数上限は `tests/test_delivery.py` で確認できます。
実際に配信する場合の設定と制約は [README](../README.md) を参照してください。
